# UptimePulse

Веб-приложение мониторинга доступности сайтов и сервисов с замером задержки (мс), фоновым опросом и хранением целей в SQLite.

## Запуск

Требуется Docker Engine и Docker Compose.

```bash
unzip uptime-pulse-fixed.zip
cd uptime-pulse
docker compose up -d --build
```

Открыть: `http://localhost:8080` (или `http://<IP-сервера>:8080`).

## Остановка

```bash
docker compose down
```

Данные SQLite сохраняются в Docker volume `pulse_data`. Чтобы удалить данные вместе с контейнерами, используйте `docker compose down -v`.

## Безопасность и ограничения

- Мониторинг принимает только HTTP/HTTPS и порты 80/443.
- Локальные и непубличные IP-адреса блокируются, включая адреса, полученные через DNS.
- Проверки не следуют HTTP-перенаправлениям, чтобы не обойти SSRF-защиту.
- Любой HTTP-ответ, включая 3xx, 4xx и 5xx, подтверждает доступность сервера; код HTTP показывается отдельно. Ответы 4xx/5xx отмечаются как ошибки HTTP, но сайт остаётся ONLINE.
- Максимум 500 целей; длина имени — 100 символов.

Приложение рассчитано на доверенную небольшую инсталляцию. Перед публикацией в интернете рекомендуется дополнительно настроить HTTPS, аутентификацию и ограничение частоты запросов на уровне reverse proxy.
